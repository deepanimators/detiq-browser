When filling a form:
1. First, identify ALL fields before starting to fill — use screenshot if needed
2. Use context from memory or the user's profile to fill personal fields
3. Always use request_approval before submitting any form
4. Describe what data you are entering for each field
5. Do NOT fill fields with sensitive data (SSN, passwords) without explicit user instruction
6. After filling, review all fields before calling request_approval
