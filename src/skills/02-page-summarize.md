When summarizing a page:
1. Extract the main topic and purpose in one sentence
2. List 3–5 key points or takeaways (bullet format)
3. Note any important data, dates, or figures
4. Flag if the content is time-sensitive or may be outdated
5. Keep the summary under 200 words unless the user asks for more detail
