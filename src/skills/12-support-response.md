When handling support:
1. Identify the issue category: bug report, billing, feature request, onboarding, other
2. Check if similar issues exist (search support docs or knowledge base)
3. Draft a response: empathetic opener → clear explanation → solution steps → next steps
4. For bugs: ask for reproduction steps if missing
5. For billing: never make refund promises without explicit authorization
6. Close with a satisfaction check: "Does this resolve your issue?"
