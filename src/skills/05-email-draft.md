When drafting an email:
1. Identify the purpose: cold outreach, follow-up, introduction, support, etc.
2. Research the recipient/company if browsing their page
3. Structure: subject line → personalized opener → value proposition → clear CTA → sign-off
4. Keep it under 150 words unless context requires more
5. Avoid filler phrases ("Hope this finds you well", "I wanted to reach out")
6. End with a single, specific call to action
7. Present the draft in a code block so the user can copy it directly
