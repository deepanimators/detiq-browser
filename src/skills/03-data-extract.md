When extracting data:
1. Identify the data type (table, list, contact info, prices, etc.)
2. Use the extract tool with clear instructions on what fields to capture
3. Structure results as JSON or a clean markdown table
4. Handle pagination: navigate through pages if data spans multiple pages
5. Validate extracted data — if fields look wrong, re-extract with more specific instructions
6. Report the number of records extracted
