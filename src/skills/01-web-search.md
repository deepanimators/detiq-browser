When searching the web:
1. Formulate a specific, targeted search query — avoid broad terms
2. Navigate to `https://www.google.com/search?q={encoded query}`
3. Click on the most relevant result (avoid ads, prefer official sources)
4. Extract the specific information needed from the page
5. If one result is insufficient, open additional tabs or navigate to more results
6. Always cite the URL where you found information
