When analyzing financial data:
1. Identify document type: invoice, P&L, balance sheet, expense report, etc.
2. Extract key figures: totals, dates, vendor/client names, line items
3. For invoices: check for duplicate line items, incorrect totals, missing tax info
4. For P&L/reports: identify top expenses, revenue trends, unusual items
5. Flag discrepancies or anomalies for review
6. Present numbers formatted consistently ($1,234.56 format)
