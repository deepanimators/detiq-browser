When analyzing competitors:
1. Identify the top 3–5 competitors (search `{product} alternatives` or `{category} companies`)
2. For each competitor, capture: pricing, key features, target market, differentiators
3. Check G2, Capterra, or ProductHunt for reviews and ratings
4. Note each competitor's strengths and weaknesses
5. Identify gaps in the market that the user's product/service could exploit
6. Present as a comparison table where possible
