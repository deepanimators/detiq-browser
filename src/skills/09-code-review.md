When reviewing code on a page (GitHub, GitLab, Stack Overflow, etc.):
1. Identify the language and context
2. Check for: bugs, security issues (SQL injection, XSS, auth flaws), performance issues
3. Note any best-practice violations
4. Suggest specific improvements with example code snippets
5. If it's a PR/diff, focus on changed lines only
6. Rate severity: critical / high / medium / low for each issue
