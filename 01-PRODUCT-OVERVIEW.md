# Strawberry Browser — Complete Product Overview

## What Is It

Strawberry is an **AI-powered desktop browser** built on Electron + Chromium. It ships AI agents called "Companions" that live inside the browser and execute multi-step web tasks on your behalf — clicking, form-filling, data extraction, scheduling, CRM updates — while you watch, pause, or guide them.

Built by **Dendrite Systems**, a Swedish startup. Raised **$6M seed** (2025–2026). Officially launched: **October 26, 2026**.

The tagline: **"The self-driving browser."**

## Core Value Proposition

1. **No coding required** — non-technical users can automate repetitive browser work via natural language
2. **Visible automation** — you watch the agent work, can pause/replay/guide it
3. **Logged-in context** — Companions operate inside your existing authenticated sessions (no re-login)
4. **Local-first privacy** — browsing history, credentials, extracted data stay on device
5. **Works with all sites** — not locked to specific integrations

| Standard Browser | Strawberry |

| No automation without extensions | Built-in agentic automation |
| Third-party scrapers needed | Native data extraction |
